Sous le Capot : Traitement Colorimétrique

Pour comparer des couleurs de manière humaine et réaliste, l'espace RVB traditionnel ne suffit pas. CineChroma utilise la conversion dans l'espace CIELAB (LAB) et l'algorithme de clustering K-Means.

1. L'Espace Perceptuel CIELAB

Contrairement au RGB, l'espace LAB sépare la clarté (L) des axes de couleurs chromatiques (a et b). La distance euclidienne delta E calculée dans cet espace correspond fidèlement à la façon dont l'œil humain perçoit la proximité entre deux nuances.

2. Clustering K-Means In-Browser

Lorsque vous déposez une image dans le module de recherche, un script Canvas natif traite les pixels en temps réel dans votre navigateur. Les centroids sont ajustés de façon itérative sans envoyer votre fichier sur un serveur externe.

// Calcul de distance Delta E dans l'espace CIELAB
function colorDistanceLAB(labA, labB) {
  const dL = labA.L - labB.L;
  const da = labA.a - labB.a;
  const db = labA.b - labB.b;
  return Math.sqrt(dL*dL + da*da + db*db);
}
